# 环境配置：本地开发 vs 服务器部署

一份代码，用环境变量区分场景。

## Windows 一键脚本

| 脚本 | 说明 |
|------|------|
| `scripts\一键启动.bat` | 本机已装 MySQL/Redis 时，开两个窗口启动前后端（脚本内提示为英文，避免 cmd 编码问题）。 |
| `scripts\start-all.bat` | 需要 Docker：先起 MySQL/Redis 再起前后端。 |

## 前端

| 场景 | 命令 | 配置 |
|------|------|------|
| 开发 | `npm run dev` | `.env.development`，接口 `/api` 走 Vite 代理 |
| 本机打包预览 | `npm run build:local` 再 `preview` | `.env.localhost` |
| 服务器 | `npm run build` | `.env.production`（勿提交敏感内容，见根目录 `.gitignore`） |

`vite` 默认端口 **3000**；`strictPort: true` 时若被占用会报错而不是悄悄改用 3001。

## 后端

数据库等用环境变量覆盖 `application.yml`；生产可设 `SPRING_PROFILES_ACTIVE=prod` 使用 `application-prod.yml`（关闭 Swagger）。

### MySQL（本地约定）

| 项 | 默认值 |
|----|--------|
| 库名 | `diet_management` |
| 账号 | `root` |
| 密码 | `123456` |

与 `docker-compose.yml` 中 `MYSQL_ROOT_PASSWORD` 一致。若本机 MySQL 密码不同，请设置环境变量 `DB_PASSWORD`，或执行 `scripts\init-db.sql` 建库后用 `mysql` 客户端改密/授权。

详见根目录 `env.example`。
